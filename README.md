# Eco Smart Mall

Bilingual Arabic/English sustainable cooperative mall prototype.

**Website source:** [site/index.html](site/index.html)  
**Implementation guide:** [site/README.md](site/README.md)  
**Automated checks:** [GitHub Actions](../../actions)

## Features in the prototype

Marketplace, demo cart, unpaid demo orders, inventory alerts, members, vendors, sample votes, transparency, language switching and right-to-left layout.

All data remains in local browser storage. No payment processing, real business data, legal ownership claims, or Glide synchronization.

## Hosting

`vercel.json` configures Vercel to publish the `site/` directory. Deployment requires connecting an authorized hosting account; this repository being on GitHub alone does **not** mean the site is deployed.

Do not submit real personal or financial data to the demo.
