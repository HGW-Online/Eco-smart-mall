# دمج HGW Quantum Security

أُضيف دليل التنفيذ المحلي إلى قطاع الأمن في الموقع وPWA، وإلى مصادر تغليف تطبيقات Capacitor/Electron عبر `npm run web:prepare`. لا يوجد إصدار متجر أو ملف تطبيق أصلي جديد.

المنصة المنشورة: https://hgw-humanity-platform.raregrass18.chatgpt.site/?section=security
الموقع التعريفي: https://hgw-io.raregrass18.chatgpt.site/#quantum-security

## نطاق الدمج
- دليل تفاعلي داخل نفس المضيف، أربع مراحل أسبوعية و16 مهمة وتصفية أدوات وتنزيل خطة.
- مشروع مستقل `quantum-security` في كتالوج المنصة، منفصل عن البحث الاستكشافي `quantum`.
- ثلاث مراحل تخطيط تُحفظ باستخدام API المنصة المعتمد والمصادقة الحالية؛ تولّد مهام مراجعة للحوكمة والتعليم والاتصالات والتجارة والسويد، مع روابط عكسية.
- لا تتغير خوارزميات الخزنة أو آلية الهوية أو بيانات المستخدمين. لا يوجد KMS أو SIEM أو TLS مقاوم للكم مفعّل بهذه الإضافة.
- قائمة الدليل تحفظ في المتصفح فقط، مستقلة عن مراحل حساب المنصة؛ لا ترسل مفاتيح أو أسرارًا.

## بدء بلا رأس مال
جهاز وكهرباء واتصال ووقت متاح مسبقًا. OpenSSL وliboqs وOpenBao وKeycloak وWazuh وPodman أدوات المسار. يلزم التحقق من الإصدار والترخيص والموارد قبل التشغيل. التدقيق المستقل وHSM والاستضافة الإنتاجية والمشورة القانونية تؤجل حتى توافر الموارد.

## بوابة الإنتاج
اختبارات وظيفية، رفض العبث، قياس أداء، استعادة وإبطال موثقان، إغلاق الثغرات الحرجة، مراجعة مستقلة وتقييم GDPR. لا تتصل التجربة بأموال أو BankID أو مفاتيح أو بيانات إنتاج حقيقية.
