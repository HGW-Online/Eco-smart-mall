# HGW Base v1 candidate — NOT production ready
Three distinct contracts. Utility uses ERC20, initial billion to explicit treasury, mint only through governance. Governance uses fixed unique voters, strict >75% of all members, 7 day vote, 2 day delay, evidence hash, per-proposal cap and replay protection. Assets is an intentionally disabled placeholder, not a securities issuance system.
Assumptions for review: fixed roster (no rotation/recovery), yes-only voting, no expiry after voting, no aggregate issuance cap, evidence hash does not establish asset value, one-time initializer binding is trusted; incorrect binding can permanently prevent minting. These are unresolved production risks. Members, treasury, cap, evidence appraisal process and legal review must be approved before deployment. No signer keys or real addresses included. No on-chain deployment performed.
Target: Base Sepolia 84532 then Base 8453 after independent audit and signing. Historical Celo DPP transaction is not proof of mint.
